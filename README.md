# ZXTune Homebrew Tap

Homebrew formulae for ZXTune applications.

The command-line formula follows the latest upstream release, currently `r5112`.

## Install the command-line player

```sh
brew tap anteo/zxtune
brew install zxtune123
```

Then play a chiptune file with:

```sh
zxtune123 path/to/music.ay
```

The tap currently contains `zxtune123`. A prebuilt bottle is available for Apple Silicon on macOS 27. Homebrew builds from source on other macOS versions and Intel Macs.
